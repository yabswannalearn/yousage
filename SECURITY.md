# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/yabswannalearn/yousage/security/advisories/new). Include the YouSage version, Windows version, affected provider, and steps to reproduce using demo data or a disposable account.

Remove credentials, usage exports, account identifiers, and conversation titles from anything you attach. For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/yabswannalearn/yousage/issues).
